# CHETAN & SHIWANGI — Ganesha artwork update

This update replaces the previous generic Ganesha watermark with the exact Ganesha artwork supplied by the couple.

## Files to replace in GitHub
- `index.html`
- `style.css`

Keep `script.js` unchanged so the existing Supabase guestbook configuration remains intact.

## Image handling
The supplied Ganesha artwork has been resized and compressed to WebP (about 87 KB) and embedded directly in `index.html`. It does not need to be uploaded separately or placed in an assets folder. The bride and groom portraits remain embedded in the HTML as in the previous mobile-friendly version.

## Publish
1. Extract this ZIP.
2. Replace `index.html` and `style.css` in the repository root.
3. Commit the changes.
4. Wait for Cloudflare to deploy, then refresh the website.

The artwork is placed as a responsive devotional feature above the invitation text. Its original floral border and mantra are preserved.
